TaskFlow - Fullstack Task Management System
TaskFlow is a web-based application designed to help users manage their tasks efficiently with features like real-time mentions and team collaboration.

🚀 Live Demo
Frontend: (https://todo-app-psi-five-17.vercel.app/)

Backend API: (https://todoapp-1-0hmw.onrender.com)

✨ Key Features
User Authentication: Secure Sign-up and Login using JWT.

Task Management: Create, Edit, Delete, and Update task status.

@Mentions: Easily tag team members by typing "@" in the assignee field.

Task Groups: Organize tasks into custom categories.

Priority Levels: Color-coded priority for better visualization.

🛠️ Tech Stack
Frontend: React.js, Vite, CSS (Custom Styles)

Backend: Node.js, Express.js

Database: MongoDB Atlas

Security: JSON Web Token (JWT)
